Design Philosophy

"Design is not just how it looks."

"I like creating experiences where visual design, interaction, and functionality work together. Whether it's a website interface or a game, my goal is to make every interaction feel intentional."

I

Intentional Form

Every pixel, margin, and type size exists for clarity, not ornament.

Design must be implementable, robust across screens, and accessible to everyone.

Project Deep Dive

LUMBO — Stylized Racing Experience

LUMBO is an interactive game project combining retro-arcade vehicle handling with modern, minimalist art direction. Designed with custom steering physics, lap-tracking algorithms, and tactile soundscapes.

Track & Path Geometry

Built using Bézier curve interpolations to generate smooth circuit bends, road banking, and off-track friction thresholds.

Dynamic Camera

Spring-based camera lagging behind vehicle acceleration and rotation to provide a visceral sense of speed.

Audio Synthesizer

Web Audio API oscillator pitch manipulation keyed to RPM curves for immediate acoustic feedback.

Ergonomic Mobile Controls

Dual thumb touch triggers engineered to prevent thumb fatigue while maintaining precise drift control.

Interactive Project Deep Dive

Candy Crush Mini — Match & Logic Grid

An exploration of game mechanics, visual feedback, and responsive matrix logic. Designed to deliver high sensory satisfaction through micro-animations, squash-and-stretch drops, and sound stagers.

Matrix Matching Engine

Bidirectional scanning for 3, 4, and 5-in-a-row match combinations with automatic cascade refills.

Physics & Easing

Cubic bezier acceleration curves simulating physical candy weight and rebound vibrations.

Color Harmony & Accessibility

Carefully calibrated palette ensuring high contrast between game pieces for effortless recognition.

Interactive State Machines

Prevents illegal multi-touch inputs while cascading animations resolve smoothly.
